hf-dll.3 · A shower of coins flies to your total · agreed

Ticking a task off sends five coins from the row to the gold pill. Each one clinks and the number climbs as it lands. On a phone scrolled down, a copy of the pill slides in to catch them. Undoing is quiet. Turn on the sound to hear the clinks.

Tap a round box to tick that task off.
The phone starts scrolled down so the pill is out of sight; scroll up to tick a task with the pill in view. Desktop shows the ordinary case. A task worth 0 coins sends nothing: no coins, no sound, no announcement. ↺ under “Klart senaste veckan” takes the coins back with no animation. The tick-boxes show the agreed behaviour; the rest of the row is drawn only roughly, and the "N mynt" on each row is there only to make the drawing readable (showing it is not part of this work).
