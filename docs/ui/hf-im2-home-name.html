The home's name under the header row on phones; desktop unchanged

On phones where the buttons sit beside the heading (such as 390 px), the home's name moves out of the narrow strip beside the buttons and gets its own line under the whole header row, so it can use the full width. The buttons stay exactly where they are; the header grows 16 px (48 → 64 px) for every home. Desktop and 300 px are unchanged. The blue dashed box marks the home's name, only in this drawing.
