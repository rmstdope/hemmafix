Option A — controls drop to their own row when they don't fit; the name stays directly under “Listor”

When the heading and the controls fit on one row, the name sits under that row at full width. When they don't (narrow phone, a long streak or a big coin balance), the order is: “Listor”, the name, then the controls on their own row, right-aligned. This is exactly what Uppgifter does at 300 px. The header is one row taller only when the controls don't fit. The blue dashed box marks the home's name, only in this drawing.
