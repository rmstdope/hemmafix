## A one-column migration made the review packet too large to paste into the reviewer's prompt

**What happened.** `review-packet hf-998 141` printed 120 KB, of which about 96 KB was the diff of
the generated `drizzle/meta/0019_snapshot.json`. `produce-bead` *The review loop* says to paste the
output whole into the sub-agent's prompt; that meant reproducing it by hand in a tool call, so the
reviewer was instead told to read the unedited file.
**Why.** drizzle-kit writes the whole schema into a new snapshot for every migration, and
`review-packet` includes every changed file's diff.
**Cost.** One rule not followed as written, and roughly three quarters of the packet spent on a
generated file in every review of a migration.
**Prevent by.** `produce-bead` *The review loop* saying how to hand over a packet too large to paste
(the file path is enough), or `.cerebro/cerebro/scripts/review-packet` naming generated files such as
`drizzle/meta/*_snapshot.json` among the changed files without their diff.
**Seen before.** none found.
